# Парсер вакансий с hh.ru

Проект для поиска, фильтрации и сохранения вакансий с платформы hh.ru. Программа позволяет получать информацию о вакансиях, сохранять ее в файл и удобно работать с ней: добавлять, фильтровать, удалять.

##  Возможности

- **Поиск вакансий**: Получение вакансий с hh.ru по ключевым словам
- **Фильтрация**: Фильтрация вакансий по ключевым словам в описании
- **Сортировка**: Сортировка вакансий по уровню зарплаты
- **Топ-N вакансий**: Получение топ N вакансий с наибольшей зарплатой
- **Сохранение**: Сохранение вакансий в JSON-файл
- **Управление**: Добавление и удаление вакансий из файла
- **Валидация**: Автоматическая валидация данных вакансий

#  Использование
После запуска программы следуйте инструкциям:

Введите поисковый запрос: Например, "Python разработчик"

Укажите количество вакансий: Сколько топовых вакансий показать

Задайте ключевые слова: Для фильтрации вакансий (через пробел)

Укажите диапазон зарплат: Например, "100000-150000"

### Пример использования в коде
python

from src.api import HeadHunterAPI

from src.vacancy import Vacancy

from src.storage import JSONSaver

## Создание экземпляра API
hh_api = HeadHunterAPI()

## Получение вакансий
hh_vacancies = hh_api.get_vacancies("Python")

## Преобразование в объекты
vacancies_list = Vacancy.cast_to_object_list(hh_vacancies)

## Работа с хранилищем
json_saver = JSONSaver()
json_saver.add_vacancies(vacancies_list)

### Получение вакансий по критериям
filtered = json_saver.get_vacancies({"title": "Python"})
